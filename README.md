# Vue 3 Auto Form

Компонент динамической генерации формы на основе JSON-схемы.

## Возможности

- text / email / password
- select
- checkbox
- required
- minLength
- pattern
- reactive v-model
- validation errors
- accessibility

## Стек

- Vue 3
- TypeScript
- Vite
- Vitest

## Запуск

npm install
npm run dev
